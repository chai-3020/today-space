# 今日空间小程序 - 舍友开发指引

欢迎加入今日空间的开发!这份指引带你从 0 到 1 搭好本地开发环境。

## 一、你需要准备的 3 样东西

1. **GitHub 账号**(已注册)
2. **微信开发者工具**(下载:https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html 选稳定版 Windows)
3. **你的微信**(用来登录开发者工具)

## 二、获取代码(3 种方式任选)

### 方式 A:git clone(推荐,参与开发用这个)

    git clone https://github.com/chai-3020/today-space.git
    cd today-space\mini-program   # 小程序代码在这里

### 方式 B:GitHub Desktop(图形界面,新手友好)

1. 下载 https://desktop.github.com 并登录你的 GitHub
2. File → Clone Repository → 选 chai-3020/today-space → 选本地目录 → Clone

### 方式 C:只看不改(浏览代码)

直接打开 https://github.com/chai-3020/today-space/tree/main/mini-program 在线看。

## 三、在微信开发者工具里打开项目

1. 打开微信开发者工具 → **微信扫码登录**(用你自己的微信)
2. 点「+」导入项目:
   - 目录选择:你 clone 下来的 `mini-program` 文件夹
   - AppID 会自动带出 wxb57a95d55bde4d5b(需要你是体验/项目成员,否则会提示无权限——找群主把你加进小程序后台的成员管理)
   - 点「确定」
3. 首次打开若提示选择云环境,选 `cloud1-d9gqbbkdz44c81883`

## 四、开发分工(按页面)

| 页面 | 代码位置 | 说明 |
|---|---|---|
| 首页/待办 | `mini-program/pages/index/` | 概览卡片 + 待办清单 |
| 番茄钟 | `mini-program/pages/pomodoro/` | 专注/短休/长休计时器 |
| 便签 | `mini-program/pages/notes/` | 自动保存的便签 |
| 统计 | `mini-program/pages/stats/` | 本周专注柱状图 |

每个页面有 4 个文件:`xxx.wxml`(结构)、`xxx.wxss`(样式)、`xxx.js`(逻辑)、`xxx.json`(配置)。
一般改 wxml 和 wxss 就能调 UI,逻辑在 js 里。

## 五、改完代码怎么提交(重要!)

⚠️ 上传版本和部署云函数**只有群主做**,你只提交代码到 GitHub:

    git add -A
    git commit -m "feat: 描述你改了什么(如:优化待办页样式)"
    git push origin main

提交前先拉一下最新代码,避免冲突:

    git pull origin main

如果 pull 提示冲突:不要慌,把冲突文件里 <<<<<<< 和 >>>>>>> 之间的内容手工合并后重新 add + commit 即可,或者找群主帮忙。

## 六、本地预览测试(不打扰别人)

在开发者工具里直接点「编译」就能在模拟器看到效果,随便改随便试,不会影响线上。
改完点「预览」可以用自己手机扫码真机测试。

## 七、提交规范(约定)

- commit 信息用中文,格式:`feat: 新功能` / `fix: 修bug` / `style: 样式调整`
- 一次 commit 只改一个页面的内容,方便回滚
- 不要提交 `project.private.config.json`(本地配置)

## 八、遇到问题

- 编译报错 → 把红色错误信息截图发群里
- 云函数相关报错 → 找群主(云环境部署统一由群主管理)
- 想加新页面 → 先问群主,涉及 app.json 路由和 tabBar 改动,容易冲突

Happy coding! 🚀
